# EduNova: Your Campus Planner + NovAi (Full Version v2.0)

Aplikasi Android lengkap untuk pengurusan jadual kuliah, tugasan, dan pembantu pembelajaran kendiri **NovAi** (Ambil Gambar Soalan + Suara ke Teks).

## Ciri Baharu NovAi (Tab Bantuan AI)
- **Karakter Maskot NovAi**: Robot burung hantu cendekiawan bertopi graduasi pada tab navigasi dan papan pemuka AI.
- **Ambil Gambar Soalan**: Murid boleh terus buka kamera atau pilih gambar dari galeri untuk mendapatkan jawapan dan langkah penyelesaian.
- **Suara ke Teks (Voice-to-Text)**: Tekan butang mikrofon untuk bertanya soalan menggunakan suara (menyokong Bahasa Melayu).
- **Integrasi Gemini AI**: Masukkan kunci API percuma dari Google AI Studio pada tab **Profil** untuk jawapan pintar sebenar.
