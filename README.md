# EduNova: Your Campus Planner + NovAi (Full Version v3.0)

Kod projek baharu sepenuhnya dari awal yang telah dibersihkan daripada sebarang ralat sintaks dan ralat pembinaan GitHub Actions.

## Cara Jana APK & AAB di GitHub
1. Ekstrak semua fail dalam `EduNova-NovAi-FullVersion-v3.zip`.
2. Muat naik ke dalam *repository* GitHub baharu (pastikan folder `.github` turut dimuat naik).
3. Klik tab **Actions** > pilih **Build EduNova + NovAi (APK & AAB)** > klik **Run workflow**.
4. Muat turun hasil binaan di bahagian **Artifacts**.
